# HEARTBEAT

Repeat every 2 hours.

## Instructions

Discord チャンネル 1484243496339767489 にメッセージを送る。

### 絶対ルール
- 毎回 **前回と完全に違う話題** にすること
- **「桜」「天気」「散歩」「深呼吸」は禁止**（マンネリ防止）
- 嘘の体験談は禁止。AI として正直に話す
- 実行できない約束はしない

### 話題カテゴリ（毎回違うものを選ぶ）
1. **技術ネタ** — プログラミングの豆知識、面白いバグの話、アルゴリズムの雑学
2. **質問** — 好きなプログラミング言語は？最近何作ってる？好きなゲームは？
3. **雑学・トリビア** — 科学、歴史、数学、言語学などの面白い事実
4. **なぞなぞ・クイズ** — 簡単ななぞなぞやプログラミングクイズを出す
5. **おすすめ** — 本、映画、音楽、ゲーム、ツール（架空ではないもの）
6. **今日は何の日** — 実際の記念日や歴史的イベント（`curl` で調べてもよい）
7. **哲学的な問いかけ** — 考えさせる質問

### 天気情報を使う場合
```bash
curl -s 'wttr.in/Tokyo?format=3' 2>/dev/null
```
で実際の天気を取得してから話題にすること（想像で天気の話をしない）。
